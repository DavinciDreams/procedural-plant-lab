# Procplants PRD implementation status

Updated: 2026-08-10

This is the execution checklist for `new features.md`. It distinguishes features that exist in the standalone generator from features supplied only by the downstream Tellus runtime. Metadata estimates are not counted as real runtime LOD, wind, or export implementations.

## Implemented in Procplants

- Deterministic Weber-Penn, branch-module, herbaceous graph, guided-vine, and space-colonization/swept-tube backends, plus a tested parametric stochastic L-system/turtle foundation.
- Species presets, hybridization, ecology profiles, and golden-angle placement. Added sugar maple, weeping willow, windswept bonsai, deadwood snag, and twilight fantasy tree with low-cost real LOD sets.
- Instanced organ rendering plus bounded reusable prototypes and instanced stems in the lab.
- Branch-relative foliage frames, upward-facing blade normals, folded/venated leaf surfaces, spreading crowns, junction blending, and deterministic tree traits.
- Low-cost fern/ground-cover forms: phi fern, bracken mat, clover, wood sorrel, woodland anemone, creeping phlox, strawberry, maidenhair fern, woodland violet, trillium, and horsetail. The four newest broad patches span roughly 1.8-2.1 by 1.8-2.0 local units and stay between 628 and 1,908 close triangles with real 4/2-triangle far tiers.
- Reduced conifer spray tiers and optimized blue spruce, alpine fir, redwood, and tundra small pine presets.
- Environment response for light, moisture, crowding, and biome warmth.
- Exact structural readiness reports for real instanced triangle/vertex cost, draw calls, materials, estimated GPU bytes, and monotonic LOD budgets.
- Public segment/attachment IR with stable IDs, parent-segment references, axial position, right-handed branch frames, attachment kind, depth, and sway weight. Weber-Penn now retains stable baked stem ancestry, child ownership, per-stem vertex/index ranges, native-leaf parentage, and topology signatures; the compiled build also exposes a stable picker graph and trim target.
- Four deterministic default, geometry-bearing LOD tiers: full geometry, coherently rebuilt reduced geometry, crossed cards, and a single-card impostor placeholder.
- A versioned renderer-independent runtime LOD-selection contract gives those four default tiers stable IDs and combines normalized distance with projected height, hysteresis, and max-distance culling. Runtime/Tellus packages retain this version-1 contract and exact canonical bytes.
- An explicit version-2 five-tier path now implements full geometry, rebuilt reduced geometry, clumped/crossed cards, a baked-atlas crossed tree impostor, and a baked billboard/hemisphere impostor. It requires a real bounded atlas bound to the exact genome/seed/LOD0 hash, fails closed on absent or stale bakes, freezes costs and hashes, renders LOD3/LOD4 in real Chrome WebGL 2, and exports a deterministic GLB with the PNG atlas and ordinary `extras`; it claims no Khronos LOD extension and is not yet adopted by Tellus.
- Standalone GPU vertex wind for visible and shadow passes. The default-compatible V1 path retains the historical sway/phase contract; the lab opts into bounded V2 hierarchical deformation with derived trunk/branch/leaf bands, stable bend anchors, leaf ripple/gust, rotated normals, and matching depth/distance-shadow hooks. Canonical combined templates without `branchOrder` fail closed to stem-versus-leaf separation rather than inventing a branch hierarchy.
- Worker-compiled, cached hero-plant LOD switching with hysteresis and no per-frame geometry allocation.
- First-class spiral, alternate, opposite, decussate, and whorled phyllotaxy contracts with authored phase/whorl count; absent configuration preserves legacy golden-angle output exactly.
- Live instanced/batched diagnostics for attachment kind, branch order/parent links, right/up/tangent frames, wind weights, and active LOD.
- Deterministic non-mutating Plant-IR pruning by segment, branch depth, height plane, or radius, with descendant/ancestor repair and an auditable before/after result.
- Viewport trim supports graph-backed plants and baked Weber-Penn trees. One static picking mesh maps click, stroke, and Shift-lasso hits to stable IDs; graph plants recompile from pruned IR, while Weber-Penn removes owner stems with descendant closure, retained-ancestor repair, and native-leaf/crown-fill cleanup. Operations persist for the same authored target, support grouped undo/reset, and stale or unsupported Weber targets preserve exact source geometry.
