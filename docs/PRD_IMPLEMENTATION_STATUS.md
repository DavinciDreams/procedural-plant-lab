# Procplants PRD implementation status

Updated: 2026-08-07

This is the execution checklist for `new features.md`. It distinguishes features that exist in the standalone generator from features supplied only by the downstream Tellus runtime. Metadata estimates are not counted as real runtime LOD, wind, or export implementations.

- Species presets, hybridization, ecology profiles, and golden-angle placement. Added sugar maple, weeping willow, windswept bonsai, deadwood snag, and twilight fantasy tree with low-cost real LOD sets.
- Instanced organ rendering plus bounded reusable prototypes and instanced stems in the lab.
- Branch-relative foliage frames, upward-facing blade normals, folded/venated leaf surfaces, spreading crowns, junction blending, and deterministic tree traits.
- Low-cost fern/ground-cover forms: phi fern, bracken mat, clover, wood sorrel, woodland anemone, creeping phlox, strawberry, maidenhair fern, woodland violet, trillium, and horsetail. The four newest broad patches span roughly 1.8-2.1 by 1.8-2.0 local units and stay between 628 and 1,908 close triangles with real 4/2-triangle far tiers.
- Reduced conifer spray tiers and optimized blue spruce, alpine fir, redwood, and tundra small pine presets.
- Environment response for light, moisture, crowding, and biome warmth.
- Exact structural readiness reports for real instanced triangle/vertex cost, draw calls, materials, estimated GPU bytes, and monotonic LOD budgets.
- Public segment/attachment IR with stable IDs, parent-segment references, axial position, right-handed branch frames, attachment kind, depth, and sway weight. Weber-Penn exports stable leaf-site and branch-tip frames where its vendor mesh cannot provide lossless segment ancestry.

## Implemented only as metadata or heuristics

- The public compiler produces separate LOD geometry, the standalone hero switches tiers by camera distance, and Weber-Penn trees, canonical graph-backed woody cohorts, and eleven audited fern/ground-cover cohorts in the dense lab use the placement pool. `ProcPlantRuntimePackage.lods` remains compact budget/distance metadata; other herbaceous cohorts still use authored fallback geometry.
- Space colonization and swept tubes are selected by one opt-in production preset with scalar tube controls and real freeform constructive crown sculpting. V1 supports oriented, resized, density-weighted positive lobes and bounded subtractive cutouts; spline volumes, per-chain tube editing, and watertight unions remain outside this implementation. Chain collars overlap rather than forming a watertight branch union.
- Canonical generator DAGs have built-in handlers for all nine stages and real architecture/branching-to-foliage dataflow. Because the production compiler is still monolithic, only allow-listed controls and representable dependencies are projected into its genome; arbitrary rewires, LOD-stage mutation, and most parent-scope semantics remain explicit unsupported audits. Stage seed overrides are an honest projection to the compiler's one global seed, not independent per-stage random streams. Macro-rule defaults are deterministic authoring transforms, not calibrated biological models.
- Spatial force fields now deform public graph branch curves by authored position/radius/direction. This remains bounded endpoint deformation rather than a physical solver, and downstream mesh geometry must be rebuilt from the returned graph.
- The resource simulator distributes vigor and carries reserve/activation/prune evidence across steps from caller-supplied or deterministic crown-occlusion probes. The opt-in topology adapter applies confirmed self-prunes and terminal `branch-tip` dormant-bud shoots, but bud selection and shoot dimensions remain bounded procedural heuristics; the model does not perform spectral/translucent radiative transfer.
- Weber-Penn trim overrides affect exported attachment IR only. Baked branch/native-leaf geometry still lacks stable vendor ancestry and is explicitly reported as unchanged.
- Material graphs now produce byte-bearing PBR resources, generated templates and every LOD have explicit UV0, mixed templates are automatically partitioned into bark/organ draw surfaces, the strict GLB binder attaches baked maps to grouped primitives, live generated plants adopt the baked PBR maps and normal/tangent contract, hero GLBs have a live import-to-spine preview/export/edit path, clustered frustum culling drives the audited standalone placement cohorts, and compact instanced forest GLB export is implemented. An immutable validated material-graph editor state model and a WebGPU compute/indirect planning contract exist, but a visual material-node UI and live GPU device/render integration remain unwired.

## Still missing from the PRD

- Arbitrary DAG semantics beyond the current compiler projections: general rewiring between every stage, independent per-stage random streams, LOD-stage mutation, arbitrary parent filters/scopes, and unconstrained stage parameters. All nine canonical handlers now run, supported piecewise scalar curves and backend depth are editable, architecture/branch capacity feeds foliage, and direct branch-relative leaf/flower/fruit placement overrides are implemented; unsupported projections are audited rather than silently simulated.
- Weber-Penn baked-topology trim recompilation. Serialized attachment-level overrides exist, but current click/stroke/lasso trimming remains graph-backend-only. Primitive and imported-mesh/BVH guide queries are implemented; vine and space-colonization collision remain static compile-time approximations, and deforming meshes require index rebuilds.
- Advanced crown/tube topology beyond the implemented transformed constructive lobe field: spline crown surfaces, per-chain tube editing, and watertight swept-branch unions. Positive/subtractive lobe UI, per-lobe resize/yaw/density, scalar global density/tube resolution/collar/roughness controls, auto-fit plus live manual mesh-spine editing/attachments, and imported-surface junction-collar displacement are implemented. The lab materializes leaf attachments but not the emitted branch/accessory attachment records. The collar helper is a visual surface swell and does not claim boolean topology.
- GLB texture compression and authored shader generation. Procedural baking, real ORM packing, texture-byte emission, lossless generated UV0, deterministic bark/organ surface partitioning, live PBR/normal-map installation, explicit tangents, UV-gated embedded grouped-primitive GLB material binding, and immutable material-graph editor state are implemented. KTX2/Basis compression, a visual material node editor, and generated custom shaders remain. Hero import extracts bounded self-contained texture bytes, but the lab does not yet resolve the selected source material into imported bark textures for preview/export. Lossless `EXT_meshopt_compression` handles geometry only; color/normal/depth atlas images remain deterministic PNGs. ASCII USDA geometry/LOD/collision export is implemented; binary USDC/USDZ packaging, textured USD materials, and automatic consumer-side LOD switching remain outside this exporter. In-file seasonal/health plus real-LOD scene variants are implemented through standard multiple-scene glTF with a Procplants selection manifest; generic viewers show the default scene unless the consumer selects another scene.
- Calibrated scientific growth simulation. Deterministic crown-occlusion probes, multi-step resource/light state, activation, growth accumulation, prune hysteresis, and first-class terminal dormant-bud shoot materialization are implemented. Species-calibrated phenology/allometry, spectral/translucent radiative transfer, and physiological validation remain future work. CLI atlas PNG decoding now covers bounded non-interlaced and Adam7 packed grayscale, 8/16-bit direct channels, indexed color, and native-precision grayscale/RGB/indexed transparency.
- Habit-aware billboard/impostor card orientation. `createPlantCardTemplate` always emits a vertical quad sized `max(width, depth)` by height, which is correct for upright habits but wrong for flat mats: measured card aspect (width/height) is 6.06 for `woodSorrelCarpet` and 6.58 for `cloverGroundcover` versus 1.02 for `blueSpruce` and 0.28 for `climbingIvy`. A carpet has almost no side profile, so its LOD2/LOD3 card renders as a wide slab standing on edge and reads as a bright flat plane in dense groundcover fields. The fix is a ground-parallel card (or an explicit habit/extent test) for the eleven `GROUND_COVER_LOD_PRESETS` cohorts; it is deferred here because it changes LOD2/LOD3 geometry and its exported hashes, which the separate Tellus LOD/biome work also touches. Full-detail LOD0/LOD1 groundcover geometry and all upright habits are unaffected.

## Tellus contract status

The contract audit used current Tellus `origin/master` at `aa3942e` (the two commits beyond the local checkout were dependency-only). Tellus still vendors a divergent copy of `tellus-procplants.ts`; it does not consume `ProcPlantRuntimePackage` as a shared library contract. Procplants now has canonical full and `procplants/core` ESM/type-library entry points, embeds generator contract revision `2` plus the additive runtime LOD-selection contract in deterministic Tellus packages, and ships fixture version 2 with UV0, attribute lengths, exact surface coverage, supported instance kinds, runtime LOD selection, biome normalization vectors, and graph/Weber-Penn/groundcover/branch-module preset hashes. An isolated Tellus worktree now accepts that byte-identical producer fixture without claiming local-generator parity. The core entry retains compiler/runtime, readiness/variants, per-organ masks, visibility clusters, biome, and Tellus package/registry APIs while excluding CLI, editor/debug, cutout/PNG, material authoring, GLB import/export/validation, and dense Three.js authoring paths.

Procplants now carries the straightforward Tellus generator additions used by this pass: junction blending, spreading crowns, folded/venated leaf geometry, and `tundraSmallPine`. The package builds its library outputs through `prepare`, keeps Vite tooling out of runtime dependencies, and tests against Tellus's Three.js 0.183.2 with Three declared as a peer. The isolated Tellus integration now vendors Maidenhair Fern Patch and Woodland Violet Carpet as explicit placement-only options beside optimized Clover; automatic paint/ecology mappings remain unchanged. Tellus has adopted the golden comparison, but still needs an immutable reviewed Procplants package plus a thin renderer adapter to stop source drift in practice.

Tellus currently substitutes external LOD2 fern assets for `phiFern` and excludes procedural `phiFern`/`blueSpruce` from global defaults. The isolated integration worktree nevertheless ports safe cost-only parity for manual/local generation: Phi Fern 6,384 to 352 triangles, Clover 1,574 to 1,226, Blue Spruce 11,840 to 5,398, and Alpine Fir 15,824 to 6,750, with broad groundcover coverage retained. Maidenhair, Clover, and Woodland Violet close templates measure 2,112, 1,226, and 2,276 triangles; all remain opt-in. Its typecheck, 58 focused contract/cost/groundcover/vegetation tests, full 426-test suite, and production build pass. Automatic mappings, served runtime behavior, and deployment remain unchanged.

## Recommended continuation order
